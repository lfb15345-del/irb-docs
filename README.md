# irb-docs — 倫理審査の申請書類を作る・添削する・点検する Claude のスキル

「人を対象とする生命科学・医学系研究に関する倫理指針」のもとで行う研究の、倫理審査（IRB）の申請書類づくりを手伝う [Claude](https://claude.ai) のスキルです。
研究計画書・同意説明文書・情報公開用文書（オプトアウト）などを機関の Word ひな形に転記して作り、指針・機関の規約・研究の実態・書類どうしの食い違いを点検します。

北海道大学病院のひな形（HT1 研究計画書・HT2 同意説明文書・HT3 情報公開用文書ほか）に対応しています。ほかの機関でも、章を読み替えれば使えます。

## できること

- **背景を、ウソのない引用つきで書く。** PubMed / Crossref で文献を探し、抄録で中身を確かめてから RIS をダウンロードし、本文の一文ごとに上付き番号を付けて文献リストを作ります。文の主張と、それを支える抄録の文の対応表も残します（AI が架空の文献を作るのを防ぐため、文献は必ずダウンロードした RIS から作ります）。
- **章ごとの書き方と、文言で気をつけるところ**（計画書24章・説明文書・情報公開文書、言い換え表）に沿って書く・添削する。
- **症例数の根拠を短く現実的に出す。** よく使う設計（2群の割合・平均、相関、精度、イベント数、生存時間）は式で計算し、計画書に貼れる文の下書きまで出します。1人を繰り返し測る研究のときだけシミュレーションを使います。
- **ひな形への転記**（注意書き・例文の削除、見出しを手がかりにした挿入、上付き引用、表紙・ヘッダーの処理）。
- **点検**: 形（機械）と中身（指針の記載事項・説明事項①〜㉒、ひな形の指示、書類どうし、実態、引用、言い回し）。

## 入れ方

### Claude Code

```bash
git clone <このリポジトリのURL> ~/.claude/skills/irb-docs
pip install python-docx scipy numpy pymupdf
```

Windows では `%USERPROFILE%\.claude\skills\irb-docs` に置きます。Claude Code を開き直すと、倫理審査の話をしたときに自動で使われます。

### Claude.ai（ウェブ・アプリ）

このフォルダを zip にまとめて（またはリリースの `.skill` ファイルを）、Claude の設定の「スキル」から追加します。

## 使うときの準備

- **ひな形・様式は同梱していません**（機関の配布物のため）。所属機関のページから取り、研究のフォルダの `様式/` に置いてください。北大病院の入手先は `references/hokudai.md`。
- **同じ診療科・部署の承認済み計画書**を手元に用意すると、表記を合わせやすくなります。
- 文献検索の連絡先として、環境変数 `IRB_DOCS_MAILTO` にメールアドレスを入れておくと、PubMed / Crossref の回数制限がゆるくなります。
- Word の PDF 化（`docx_to_pdf.ps1`）は Windows と Microsoft Word が必要です。

## 中身

```
SKILL.md                 手順の本体（Claude が最初に読む）
references/
  sections.md            章ごとの書き方と、文言で気をつけるところ
  citations.md           背景と引用（RIS のダウンロード、抄録との照合、対応表）
  sample-size.md         症例数の根拠
  shishin-checklist.md   指針との照合表（計画書の記載事項・説明事項①〜㉒）
  hokudai.md             北大病院の規約・様式・申請の流れ
  pitfalls.md            実際に踏んだ落とし穴
scripts/                 文献・症例数・転記・点検の道具（Python）
examples/                転記スクリプトの実例
evals/                   スキルの試験用の課題
```

## 注意

- このスキルは書類づくりを手伝う道具で、倫理審査の可否を判断するものではありません。最終的な判断は、研究責任者と所属機関の倫理審査委員会・事務局に従ってください。
- 指針・規程・ひな形は改訂されます。使う前に最新版を確かめてください。
- 研究対象者の個人情報を Claude に入力しないでください。

## 由来

2026年に北海道大学病院の一括審査に出した観察研究の書類づくりで、実際に踏んだこと（ひな形の消し残し、引用のずれ、書類と実態の食い違い）をもとにまとめました。改善の提案は Issue や Pull Request でどうぞ。
