# 症例数の根拠（計画書 HT1 13章）

委員会が見ているのは「この数で目的が達せられるか」「その数は本当に集まるか」の2つ。
凝ったシミュレーションより、**仮定とその出どころ・式・結果・実施可能性**が短く筋道立っている方が通る。
数字は現実的に置く（期待する効果を大きく置くほど必要数は小さくなるが、根拠のない楽観は指摘される）。

## まず型を決める

| 研究の型 | 根拠の書き方 | 道具 |
|---|---|---|
| 後ろ向き・記述・探索的（既存の診療情報など） | 「探索的研究であり、検出力に基づく症例数設計は行わない」＋**対象期間に該当する見込みの実数**（過去の実績から）。必要なら推定の精度（95%信頼区間の幅）も | `proportion-precision` / `mean-precision`、`--per-year --years` |
| 2群の比較（主要評価項目が割合） | 対照群の割合（文献・自施設）と、臨床的に意味のある差 | `two-proportions` |
| 2群の比較（平均） | 群間差と標準偏差（どちらも出どころを書く） | `two-means` |
| 前後比較・対応のある比較 | 差の平均と差の標準偏差 | `paired-means` |
| 相関・関連 | 見込む相関係数 | `correlation` |
| 多変量の調整（ロジスティック回帰） | 調整する変数の数 × 1変数あたりのイベント数（10 は目安）÷ 発生割合 | `logistic-events` |
| 生存時間の比較 | ハザード比と、観察期間中のイベント割合 | `survival` |
| 1人を繰り返し測る（日々の計測など） | 式では表しにくい。**このときだけ**シミュレーション | `power_sim.py` |

```bash
python scripts/sample_size.py two-proportions --p1 0.20 --p2 0.10 --dropout 0.1 --per-year 120 --years 3
```

出力には、必要数と、計画書に貼れる文の下書きが出る。【　　】に仮定の出どころ（文献番号、自施設の過去○年の実績）を書き足す。

**集まる数が先に決まっているとき（後ろ向き研究に多い）は逆に出す。** 効果の大きさ（`--p2`・`--delta`・`--r`・`--half-width`・`--vars`・`--hr`）を省いて `--n`（使える症例数の合計）か `--per-year --years` を入れると、その数で検出できる差・推定の精度・入れられる説明変数の数が出る。2群に分かれる数が偏るなら `--ratio`（群2÷群1）を入れる。

```bash
python scripts/sample_size.py two-proportions --p1 0.20 --n 500 --ratio 0.43 --dropout 0.05
#  → 群1 20% に対して、群2 が 32.6% 以上（または 9.4% 以下）なら検出できる ＋ 文例
```

## ひな形の例との対応（北大病院 HT1 13章）

13章の設定根拠には例が4つ載っている。研究に合う例を1つ選び、その形で書く。

| ひな形の例 | 使う場面 | 道具 |
|---|---|---|
| 例1 群間比較 | 主要評価項目で2群を比べ、差を検出したい | `two-proportions` / `two-means` / `survival` |
| 例2 単群 | 1群の割合・平均を推定したい（信頼区間の幅で根拠を示す） | `proportion-precision` / `mean-precision` |
| 例3 実施可能性から | 集まる数が先に決まっている。その数で検出できる差を示す | 各設計を `--n`（逆に出す） |
| 例4 統計学的な根拠なし | 探索的・記述的。集まる見込みの数だけを示す | 計算なし（下の文例「後ろ向き・探索的」） |

例3と例4で迷ったら例3にする。数字が1つ添えてあるだけで「この数で何が言えるか」が委員に伝わる。

## 書き方の型

- **仮定の出どころを1つずつ書く。** 「対照群の割合20%は、当院の過去3年の実績（○例中○例）による」「標準偏差は先行研究{{n}}による」。文献を付けるなら、その数値が抄録・本文に実際にあることを確かめる（citations.md）。
- **脱落・欠測を見込む。** 何割を見込むか、その理由（追跡の難しさ、記録の欠け方）。
- **実施可能性を添える。** 必要数が期間中に本当に集まるか。足りないなら期間・施設数・仮定を見直す。足りないまま「目標」とだけ書かない。
- **主要評価項目と解析と症例数を同じ量でそろえる。** 6章（評価項目）で定義した量を、13章の解析で推定し、その量で症例数を出す。評価項目は「予測率」、解析は「変化率」、症例数は「相関」のようにずらさない。
- **探索的研究の書き方。** 「群間比較のための検出力に基づく設計は行わない」と明記したうえで、推定の精度か、集まる見込みの数を書く。「十分な症例数を確保する」のような根拠のない文で済ませない。
- **長くしない。** 13章の症例数の部分は数行〜表1つで足りる。シミュレーションをしたときだけ、設計・真値・回数・結果の表を載せる。

## 文例

後ろ向き・探索的:
> 本研究は探索的研究であり、検出力に基づく症例数設計は行わない。対象期間（2019年1月〜2024年12月）に当院で【術式】を受けた患者は約○例であり【過去の実績】、選択基準・除外基準を当てはめると約○例が解析対象となる見込みである。

2群の割合:
> 主要評価項目である術後30日以内の【合併症】の割合を、従来法20%（当院の2021〜2023年の実績）、新法10%と仮定し、両側有意水準5%、検出力80%で2群の差を検出するのに必要な症例数は各群219例（連続性補正あり）である。脱落を10%見込み、合計488例とした。

実施可能性から（集まる数で検出できる差）:
> 対象期間に解析対象となる見込みの症例数は約500例【過去の実績】であり、【群2】は約3割と見込まれる。【群1】の【　　】の割合を20%【根拠】とすると、【群1】約350例・【群2】約150例で、両側有意水準5%、検出力80%で検出できるのは【群2】の割合が32.3%以上の場合である。

## シミュレーション（power_sim.py）を使うとき

1人を何十日も測る集中的縦断デザインなど、式では人数と1人あたりの観測数の両方が効く設計。
予備データの値（個人内のばらつき、曝露のばらつき、傾き、個人差）を「真値とみなして」何千回か模擬し、人数ごとの検出力と推定の幅を表にする。
設計・真値・有意水準・回数・結果を計画書に書く。引用はその主張を実際に述べている文献だけにする（「20〜30人で足りる」を支えない文献を付けない）。

## よくある指摘

- 期待する差の根拠がない（「臨床的に意味のある差」と書くなら、なぜ意味があるかを1文で）。
- 必要数が期間中に集まらない（実施可能性の記載がない）。
- 主要評価項目と症例数の計算の量が違う。
- 脱落の見込みがない、または理由がない。
- 探索的研究なのに検定の検出力の文だけが書いてある（何を検定するのかが計画にない）。
