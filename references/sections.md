# 章ごとの書き方と、文言で気をつけるところ

北大病院の雛形（HT1 研究計画書 2024年12月版・HT2 同意説明文書 2024年12月版・HT3 情報公開用文書 2025年4月版）の章立てに沿う。
ほかの機関の雛形でも、指針が求める事項は同じなので、章の名前を読み替えて使える（`shishin-checklist.md` が指針との対応表）。

## 目次
1. どの書類にも共通する決まり
2. 研究計画書（HT1）24章
3. 同意説明文書（HT2）15章と同意文書・撤回書
4. 情報公開用文書（HT3、オプトアウト）
5. 言い換え表（避ける言葉 → 使う言葉）

---

## 1. どの書類にも共通する決まり

- **書類と実態を一致させる。** 取得する情報、保管する場所、データを扱う人、対象者がすることは、実際の手順・システムと同じに書く。書類だけきれいにすると、変更申請や監査で困る。
- **書類どうしを一致させる。** 計画書・説明文書・情報公開文書で、課題名、期間、人数、取得項目、所要時間、撤回後の扱い、二次利用、保管期間が同じか。数字は1か所で決めて写す。
- **読み手に合わせる。** 計画書は委員（専門外の人も含む）向けに「である」調。専門用語は避けるか注釈を付け、略語は初出で正式名称（英略語は日本語訳も）。説明文書と情報公開文書は対象者・家族向けに「です・ます」調で、1文を短く。
- **該当しない章は消さない。** 項目番号をそのまま使って「該当なし」と書き、なぜ該当しないかを1文添える（「侵襲を伴わないため」など）。
- **推測で埋めない。** 氏名、職名、人数、期間、事業者名など、研究者にしか分からないことは【　　】のまま残し、聞く。
- **研究で使う仕組みには名前を付けて定義する。** アプリやサーバーを使うなら「本研究で用いる記録アプリと研究用サーバー（以下「システム」）」のように最初に定義し、以後は同じ呼び方にする。

## 2. 研究計画書（HT1）

### 1．研究の背景
- **書くこと**: 現状（疫学・臨床上の問題）→ 分かっていること（文献）→ 分かっていないこと → この研究で何を明らかにするか、の順。予備データがあれば「研究者らの予備的観察では」として実数で書く（引用は付けない）。
- **気をつける**: 主張は1文に1つ。各主張に文献を付け、その文献の抄録で数値・対象・向きを確かめる（`citations.md`）。「初めて」「画期的」「全く分かっていない」「確立していない」は根拠がない限り使わない。主張と逆の系統的レビューがあれば無視しない。研究の動機に商用化・製品化・個人的な事情を書かない（目的は学術的・社会的な意義で書く）。

### 2．研究の目的
- **書くこと**: 1〜2文。「〜を明らかにする」「〜を推定する」「〜を探索的に検討する」。6章の主要評価項目と対応させる。
- **気をつける**: 観察研究で「有効性を証明する」「因果関係を示す」と書かない。目的に書いたことは、評価項目と解析で必ず受ける。

### 3．研究対象者及び適格性の基準
- **書くこと**: 対象（疾患・手術・職種など）、期間（後ろ向きなら診療日の範囲 YYYY年M月〜YYYY年M月）、選択基準、除外基準（それぞれ理由が分かるように）、人数の見込み。代諾者・アセントが要るなら(5)に手続き。
- **気をつける**: 弱い立場になりうる人（研究者の部下、学生、研究者自身、同意能力の低い人）を含むなら、自由意思をどう守るか（上司は説明を担当しない、参加の有無は処遇に影響しない、参加の有無を上司に伝えない）を書く。選択基準の機器・端末は実態に合わせる（「iPhone を所有する者」と書いて Android の人が来たら困る。対応端末を書く）。

### 4．研究の方法
- **書くこと**: デザイン（前向き/後ろ向き、観察/介入、単施設/多機関）、手順を時系列で（対象者がすること、研究者がすること、いつ・何回・何分）、**取得する情報の一覧（全部）**、取得方法（診療録からの転記、質問票、機器、システム）、侵襲・介入の有無とその理由。
- **気をつける**: 取得項目は「解析に使うもの」ではなく「取得するもの全部」を書く（学会抄録と逆）。システムを使うなら、データベースの項目・アプリの入力欄・外部サービスと突き合わせて一覧を作る。手入力を「自動」「入力不要」と書かない。通常診療で行うこと（研究のために追加しないこと）と、研究のために追加することを分けて書く。

### 5．予想される利益及び不利益（負担及びリスク）
- **書くこと**: 対象者への直接の利益（多くは「ない」）、社会的な利益、負担（時間・回数・来院・入力の手間・装着）、リスク（個人情報の漏えい、皮膚のかぶれ等）、それぞれの最小化の対策、総合評価。
- **気をつける**: 「リスクはない」と書かない。「身体的な危険は想定されない。情報の漏えいのおそれがあるため、○○で対策する」のように具体的に。負担は数字で（毎朝○分、1日○分の入力）。謝礼がないなら「直接の利益はない」と正直に。

### 6．評価項目（エンドポイント）
- **書くこと**: 主要評価項目は1つ（定義・時点・測り方・単位）。副次評価項目を列挙。
- **気をつける**: 13章の解析で推定する量と同じ量・同じ単位にする（ここで「予測率」、解析で「変化率」のようなずれは指摘される）。

### 7．個々の研究対象者における中止基準及び実施後の対応
- **書くこと**: 個々の対象者の中止（同意撤回、継続が困難、研究責任者の判断）、中止後に集めたデータの扱い。研究実施後の医療（観察研究は「通常の診療を超える医療行為を伴わないため該当なし」）。
- **気をつける**: 撤回後のデータの扱い（その時点までのデータを使うか、廃棄するか、論文発表後は除けない）を説明文書7章と同じにする。

### 8．研究により得られた結果等の取扱い
- **書くこと**: 個人の結果を本人に返すか（返すなら方法、返さないなら理由）。偶発的な所見の扱い。
- **気をつける**: 研究用の数値を本人に見せる仕組み（アプリの表示など）があるなら、診断ではない旨と、気になるときの相談先を書く。

### 9．有害事象発生時の研究対象者への対応
- **書くこと**: 起こりうる有害事象（機器による皮膚刺激など）と対応。重篤な有害事象の報告の手順（侵襲のない観察研究なら該当なしの理由）。
- **気をつける**: 雛形の手順（(1)〜(4)など）を残したまま「該当なし」と書いて矛盾させない。

### 10．研究実施・変更の承認／11．研究の中止、終了
- **書くこと**: 雛形の定型文。多機関なら一括審査用の文（研究代表者が改訂を共同研究機関の研究責任者に報告する旨）を残す。
- **気をつける**: 定型文が青字で、色の一括削除で消えることがある。消えたら承認済みの実例から写して戻す。

### 12．研究実施期間
- **書くこと**: 「研究機関の長の実施許可日から YYYY年M月D日まで」。後ろ向きなら、利用する情報の対象期間（診療日の範囲）を別に書く。前向きなら登録期間。既存情報も使うなら、その対象期間。
- **気をつける**: 表紙の期間（テキストボックスの中にあることがある）、説明文書6章、情報公開文書と同じにする。

### 13．目標症例数とその設定根拠及び解析方法
- **書くこと**: 目標症例数、設定根拠（`sample-size.md`）、解析方法（主要評価項目の解析：モデル・変数・有意水準・欠測の扱い。副次・探索の解析。中間解析の有無）。
- **気をつける**: 根拠は短く筋道立てて（仮定の出どころ→式→結果→脱落→実施可能性）。探索的なら「検出力に基づく設計は行わない」と明記し、精度か集まる見込みの数を書く。多重性（主要は1つ、副次は探索的に解釈）を書く。

### 14．研究対象者の人権に対する配慮
- **書くこと**: 雛形の定型文に、**相談窓口の1文**を自分で足す（指針の「相談等への対応」）。自由意思への配慮。
- **気をつける**: 定型文だけで終わらせない。

### 15．個人情報の取り扱い
- **書くこと**: 仮名化の方法（研究用 ID、対応表を作るか・誰がどこで保管するか）、データの保管場所（院内のサーバー、外部のクラウドなら事業者名と国内リージョン）、通信の暗号化、アクセスの制限、バックアップの置き場所、仮名加工情報・匿名加工情報を作るか。
- **気をつける**: 「個人情報は使用しない」「一切」「外部に出ることはない」と書かない（共同研究機関やクラウドがあれば誤り）。対応表を残すなら「匿名化」と言わない（「仮名化」）。国外の事業者（クラウド、メール送信、生成AI、ウェアラブルのクラウド）を使うなら、外国にある者への提供・委託に当たるかを事務局に確かめ、当たるなら国名と相手の措置を書く。生成AIに個人情報を入力しない（入力するなら、その旨と事業者）。

### 16．同意取得方法
- **書くこと**: 手続きの種類（文書による IC／口頭＋記録／適切な同意／オプトアウト）と、それを選ぶ理由。説明する人（上司・指導者でない人）。説明事項①〜㉒の一覧（該当しない番号は「本研究に該当しないため記載しない」とまとめる）。撤回の方法。代諾・アセント。
- **気をつける**: 電磁的な同意（電子同意）は、本人確認・質問の機会・同意後も説明を見られることを満たし、画面を申請資料として出す必要がある。最初は文書で始め、仕組みができてから変更申請するのが通しやすい。

### 17．研究対象者の健康被害への対応と補償
- **書くこと**: 侵襲がないなら「侵襲を伴わないため補償は準備しない」と理由を添え、皮膚のかぶれ等が起きたときの対応（通常の診療で対応する）を書く。侵襲があるなら補償（保険）の内容。

### 18．研究機関の長への報告内容及び方法
- **書くこと**: 雛形の定型文（進捗、終了、重篤な有害事象、不適合の報告）。そのまま使えることが多い。

### 19．研究対象者の費用負担
- **書くこと**: 対象者の費用（ない、または通常の診療の範囲）。謝礼（あり・なし、金額、支払い方法、時期）。
- **気をつける**: 機器を貸すなら、費用の負担と返却を書く。通信料など対象者に生じうる小さな負担にも触れる。

### 20．試料・情報等の保管及び廃棄の方法
- **書くこと**: 保管場所、保管期間（雛形は5年。共同研究機関の規程が長ければ長い方）、廃棄の方法、(1)情報の授受の記録（多機関）、(4)将来の研究への利用や他機関への提供の可能性（想定される内容、そのときの手続き）。
- **気をつける**: 保管期間を説明文書10章と同じにする。「研究終了後すぐに廃棄する」と書いて、論文の審査対応でデータを見返せなくならないようにする。

### 21．研究に関する情報公開の方法及び研究結果の公表
- **書くこと**: 臨床研究の登録（介入研究は jRCT 等への登録が必要。観察研究は任意で、登録するなら登録先）、結果の公表（学会・論文、個人が特定されない形で）。

### 22．研究資金及び利益相反
- **書くこと**: 資金源（講座の研究費、科研費、研究者の自費など、実態どおり）、利益相反（企業との関係、機器の無償提供・貸与、共同研究契約）。手続き（利益相反の自己申告）。
- **気をつける**: 「該当なし」とだけ書かず、何がないのかを書く。研究中に生じたら申告する旨。

### 23．研究実施体制
- **書くこと**: 研究責任者（多機関なら研究代表者）、研究分担者、研究協力者、研究事務局、データマネジメント・統計解析の担当、共同研究機関とその研究責任者、業務委託先（あれば内容と監督方法）、一括審査を受けるか。
- **気をつける**: 研究責任者になれる職位は機関が決めている（北大病院では医員はなれない。`hokudai.md`）。所属・職名は正式名称で（同じ診療科の承認済み計画書に合わせる）。**データを実際に扱う人は必ず載せる。研究対象者として計測されるだけの人は研究者欄に書かない。**

### 24．参考資料・文献リスト
- **書くこと**: 本文の登場順に番号を振り、本文の該当箇所に上付き番号。書式は `citations.md`。
- **気をつける**: 文献リストのすべてが本文で引用されていること、番号が登場順の連番であること、RIS からの書誌事項（巻・頁・DOI）が正しいこと。

## 3. 同意説明文書（HT2）

対象者が読む。「です・ます」調、1文を短く、専門用語には説明を添える。計画書と数字・言い方を必ず合わせる。

| 章 | 書くこと | 気をつける |
|---|---|---|
| 表紙 | 課題名、病院名、研究責任者 | 一括審査では、表紙・15章の病院名と研究責任者・連絡先を**空欄のまま**にする（各機関が実施許可のときに書く） |
| 1. 臨床研究について | 委員会の承認と研究機関の長の許可のもとで行う旨（定型文） | 定型段落が赤字の注記と同じ行にあり、消えやすい |
| 2. 意義と目的 | なぜこの研究をするか、**あなたが選ばれた理由**（説明事項⑤） | ⑤は抜けやすい |
| 3. 方法 | 対象者がすることを時系列で、何を記録・取得するか | 計画書4章の取得項目と同じに |
| 4. 利益と不利益 | 直接の利益（多くはない）、負担（時間・回数を数字で）、リスクと対策 | 「危険はありません」と書かない |
| 5. ご協力をお願いすること | 箇条書き | 導入文「ご協力をお願いすることは次の○点です」の数と箇条の数を合わせる |
| 6. 期間と人数 | 期間、全体の人数（当院の人数） | 計画書12章・13章と同じに |
| 7. 参加と撤回 | いつでも撤回できる、参加しない・撤回しても不利益はない、撤回後のデータの扱い | 上司と部下の関係があるなら、参加の有無が処遇に影響しない・上司に伝えないことも |
| 8. 中止する場合 | 研究者の判断で中止する場合 | |
| 9. 情報の提供 | 研究計画書の閲覧、結果の公表、個人の結果の扱い | 計画書8章・21章と同じに |
| 10. データや検体の取り扱い | 仮名化、保管場所・期間、廃棄、将来の利用・他機関への提供、外国への提供 | 計画書15章・20章と同じに。「匿名」と「仮名」を混同しない |
| 11. 健康被害 | 補償の有無と理由、起きたときの対応 | |
| 12. 費用負担、研究資金 | 費用、謝礼、資金、利益相反 | |
| 13. 知的財産権 | 帰属 | |
| 14. 研究組織 | 研究機関、研究責任者・代表者、一括審査の旨 | |
| 15. 担当者と連絡先 | 相談窓口 | 枠の指示に従う |
| 同意文書・撤回書 | 課題名の行、研究期間、宛名、説明事項のチェック一覧、署名欄 | 課題名の行と宛名は「○○」を含む黒字で、例文の一括削除で消える。消えたら書き戻す。チェック一覧の項目と本文の章を合わせる |

**患者向けの言い回しを研究に合わせる。** 雛形には「治療」「患者さん」「カルテ」「検体」「これからの治療に影響することはありません」「最も適切と考える医療を提供します」がある。医療者が対象の研究、検体を取らない研究なら直す（一括置換は一般論の文の意味を変えるので、前後を読んで直す）。

## 4. 情報公開用文書（HT3、オプトアウト）

既存の情報だけを使う観察研究で、本人の同意を個別に取らない代わりに、研究の実施を知らせて拒否の機会を設ける書類。読むのは患者さんと家族。

| 項目 | 書くこと | 気をつける |
|---|---|---|
| [研究課題名] | 計画書と同じ課題名 | 1字でも違うと指摘される |
| [研究機関名・長の氏名] | 定型 | 病院長の氏名・住所が申請時点で正しいか |
| [研究責任者所属・氏名] | 正式名称 | |
| [研究の目的] | 簡潔に（2〜3文） | 専門用語を避ける |
| ○対象となる患者さん | 対象の期間・条件（「YYYY年M月〜YYYY年M月に当院で○○を受けた方」） | 計画書3章と同じ期間 |
| ○利用する検体・情報 | 項目を具体的に（年齢、性別、診断名、検査値、手術記録など） | 「診療情報」とだけ書かない |
| 〇送付方法 | 業務委託先や他機関に送るときの方法 | 該当がなければ項目の扱いを雛形の指示に従う |
| [研究実施期間] | 計画書12章と同じ | |
| 連絡先・相談窓口 | 拒否の申し出先 | 「＊上記の研究に…ご了解いただけない場合は以下にご連絡ください」は**拒否の機会を示す要の文**。消さない |

- 雛形には①当院単独の版と②当院が主導する多機関の版の2ページがある。使う方だけ残す。②の「当院（共同研究機関）の連絡先」は審査依頼時は空欄。
- 「個人情報は使用しません」「一切含めません」「院外に出ることはありません」とは書かない。他機関・海外へ提供するなら、その方法（記録媒体、郵送、電子的な送信）を書く。

## 5. 言い換え表

| 避ける | 使う・こう書く | 理由 |
|---|---|---|
| 匿名化（対応表を残すのに） | 仮名化（研究用 ID に置き換え、対応表は○○が保管） | 対応表があれば個人に戻せるので「匿名」ではない |
| 個人情報は一切使用しない／外部に出ない | 氏名等を研究用 ID に置き換えて扱う／共同研究機関・○○社のクラウド（国内）に保管する | 実態と違うと信用を失う |
