## 1. 研究計画書に書くこと（指針 第7）

北大の雛形（2024年12月版）の24章はこれを網羅している。該当しない章も**番号を残して「該当なし」と理由を書く**（雛形の指示。消すと予備審査で戻される）。

| 目的及び意義 | 1, 2 |
| 方法及び期間（試料・情報の取得・利用の方法を含む） | 4, 12 |

## 2. 同意説明文書で説明すること（指針 第8の6。令和5年版は第8の5。①〜㉒の中身は同じ）

北大雛形16章の原文。計画書16章にはこの一覧を置き、**該当しない番号は「本研究に該当しないため記載しない」とまとめて明記**する。説明文書は該当する番号すべてに本文を持たせる。

| # | 事項 | 説明文書（北大雛形）での置き場所の例 |
|---|---|---|
| ① | 研究の名称及び研究機関の長の許可を受けている旨 | 1章 |
| ② | 研究機関の名称と研究責任者の氏名（多機関なら研究代表者・共同研究機関、研究協力機関や既存試料・情報等の提供のみを行う者を含む） | 14, 15章 |
| ③ | 研究の目的及び意義 | 2章 |
| ④ | 研究の方法（取得した試料・情報の利用目的及び取扱いを含む）及び期間 | 3, 6章 |
| ⑤ | **研究対象者として選定された理由** | 2章（抜けやすい。実際に抜けていた） |
| ⑥ | 負担並びに予測されるリスク及び利益 | 4章 |
| ⑦ | いつでも撤回できる旨（撤回に従った措置が困難な場合はその旨と理由） | 7章 |
| ⑧ | 同意しない・撤回しても不利益な取扱いを受けない旨 | 7章 |
| ⑨ | 研究に関する情報公開の方法 | 9章 |
| ⑩ | 求めに応じて研究計画書等を入手・閲覧できる旨と方法 | 9章 |
| ⑪ | 個人情報等の取扱い（加工の方法、仮名加工情報・匿名加工情報を作るならその旨） | 10章 |
| ⑫ | 試料・情報の保管及び廃棄の方法 | 10章 |
| ⑬ | 資金源、研究機関と研究者等の利益相反 | 12章 |
| ⑭ | 研究により得られた結果等の取扱い | 9章 |
| ⑮ | 相談等への対応（遺伝カウンセリングを含む） | 15章 |
| ⑯ | 外国にある者に試料・情報を提供する場合（委託を含む。令和8年版は共同利用も）は、その国の名称と個人情報保護制度、提供先の措置 | 該当すれば10章。**国外のクラウド・メール送信・バックアップの事業者**を使うなら、委託・共同利用・提供に当たるかを事務局に確かめ、当たるならここに書く |
| ⑰ | 経済的負担又は謝礼がある場合はその旨と内容 | 12章 |
| ⑱ | 通常の診療を超える医療行為を伴う場合、他の治療方法等 | 観察研究は非該当 |
| ⑲ | 通常の診療を超える医療行為を伴う場合、研究実施後の医療の提供 | 観察研究は非該当 |
| ⑳ | 侵襲を伴う場合、健康被害に対する補償の有無と内容 | 11章。侵襲なしなら、雛形の例文（「補償は準備しない」「補償はありません」）に、侵襲がないためである理由と、皮膚のかぶれ等が起きたときの対応を添える |
| ㉑ | 同意時点で特定されない将来の研究や他機関への提供の可能性、想定される内容、確認の方法 | 10章 |
| ㉒ | 侵襲（軽微を除く）かつ介入の場合、モニタリング・監査・委員会が情報を閲覧する旨 | 観察研究は非該当 |

丸数字は ⑪=11 ⑫=12 ⑬=13 ⑭=14 ⑮=15 ⑯=16 ⑰=17 で、①〜㉒に欠番はない。字形が似ていて数え違えやすいので、計画書の一覧を作ったら22個あるかを数える。

## 3. 手続きの種類（IC・オプトアウト・電子同意）

- **既存情報だけを使う観察研究**は、オプトアウト（情報公開用文書 HT3）で足りることが多い。計画書16章には雛形の別の一覧（指針の通知・公開事項①〜⑪。令和8年版は第8の7、令和5年版は第8の6。中身は同じ）がある。`dump_template.py HT1… --grep 利用` で読んでから書く。
- **オプトアウトで足りる条件**は版で書き方が違う。計画書16章に、どれに当たるかを書く。
  - 令和5年版（第8の1⑵⑶）: 学術研究機関等が学術研究目的で扱う必要があり、権利利益を不当に侵害するおそれがない。または特段の理由があり、同意を受けるのが難しい。
  - 令和8年版（第8の2⑵イ・⑶ウ）: 情報が適切な手続で取得されていて、個人情報保護法 第18条第3項の各号（他機関へ渡すなら第27条第1項の各号）のどれかに当たる。または取得時に㉑の同意があり、その範囲で研究の内容が特定された。号は法の条文で確かめて書く。
- **本人から新たに情報を取る**なら IC が基本（北大は同意文書に署名する形）。令和8年版の本文は IC の形を決めていない（令和5年版の「侵襲ありは文書」「口頭＋記録」の規定がなくなった）。形はガイダンスと機関の手順に従う。
- 侵襲・介入・試料がなく、要配慮個人情報を含まない情報だけを新たに取る研究は、指針上は通知・公開（①〜⑪）＋拒否の機会でもよい（令和8年版 第8の2⑶イ。令和5年版も同じ）。
- **「適切な同意」（北大 HT4）は令和8年版でなくなった。** 令和8年版で書くなら、IC か、通知・公開＋拒否の機会にする。
- 電磁的方法（電子同意）は、本人確認・質問の機会・同意後も説明事項を見られる（求めがあれば文書を渡す）の3つを満たす（令和8年版 第8の3、令和5年版 第8の2。要件は同じ）。画面を申請資料として出す。最初は文書で始め、電子同意は画面ができてから変更申請するのが通しやすい。
- 研究者自身が対象者になる研究、上司と部下の関係がある研究では、自由意思の担保（辞退しても不利益なし、上司は説明を担当しない、参加の有無を上司に伝えない）を計画書3章と説明文書7章に書く。研究代表者が診療科長なら、対応表を誰が保管するかも聞かれうる。

## 4. 侵襲・介入の区分と、それで変わる項目

| 区分 | 変わる項目 |
|---|---|
| 侵襲なし・介入なし（ウェアラブル計測、質問票、既存情報） | 補償⑳・モニタリング㉒・重篤な有害事象の報告は非該当。北大は書面審査の対象 |
| 軽微な侵襲 | 補償の要否を書く。有害事象の対応を書く |
| 介入あり（侵襲の有無を問わない） | jRCT 等への事前登録（第6の4⑴） |
| 侵襲（軽微を除く）かつ介入 | モニタリングと、必要に応じて監査（第14）。説明事項㉒ |
| 侵襲（軽微を除く）かつ通常の診療を超える医療行為 | 補償のための保険等（第6の1⑺） |
| 多機関で、侵襲（軽微を除く）か介入のどちらかがある | 一括審査が必須（令和8年版 第6の2⑵。ほかは原則一括。令和5年版は全部「原則」） |

ウェアラブル機器の装着や日々の入力は、負担はあっても侵襲には当たらない。負担（時間、皮膚のかぶれ、個人情報の扱い）は5章と説明文書4章に具体的に書く。

## 5. 令和8年版（2026-12-01〜）の手続きの選び方（第8の2）

| 研究 | 手続き |
|---|---|
| 侵襲あり、または介入あり | IC（⑴） |
| 新たに試料を取る | IC（⑵ア） |
| 既存の試料を、個人を識別できない状態で使う・渡す | 手続き不要（⑵イ(ア)） |
| 既存の試料・情報を自機関で使う | 適切な手続で取得済みで、個人情報保護法18条3項の各号か、取得時の㉑の同意に当たれば、通知・公開（第8の7 ①〜③・⑦〜⑩）＋拒否の機会。当たらなければ IC（⑵イ(イ)・⑶ウ(ア)） |
| 既存の試料・情報を他機関へ渡す | 27条1項の各号か㉑に当たれば、通知・公開（①〜⑥・⑨〜⑪）＋拒否の機会。当たらなければ IC（⑵イ(ウ)・⑶ウ(イ)） |
| 取得時に別の研究の同意だけがある（目的に相当の関連性） | 通知・公開（①〜③・⑦・⑧）（同じ条のただし書） |
| 試料なしで、新たに要配慮個人情報を取る | IC。拒否の機会＋第8の9⑴①〜③＋20条2項の各号なら、第8の9⑵の措置で代えられる（⑶ア） |
| 試料なしで、新たに要配慮個人情報以外を取る | 通知・公開（①〜⑪）＋拒否の機会（⑶イ） |
| 仮名加工情報・匿名加工情報・個人関連情報 | 個人情報保護法どおりに扱う（第8の1⑴） |
| 外国にある者へ渡す（委託・共同利用を含む） | 上に加えて第8の2⑹（IC か、例外 (ア)〜(エ)） |

令和8年版のガイダンスが出たら、IC の形・「実施中」の範囲・法の号の書き方を確かめて、この表を直す。
